## 📝 O que eu aprendi até agora

- [x] Diferença entre SQL e MongoDB (tabela → coleção, linha → documento, coluna → campo)

- [x] CRUD: `insertOne`, `find`, `updateMany`, `deleteMany`
- [x] Filtros: `$gt`, `$lt`, `$lte`, `$ne`, `$or`, regex no lugar do `LIKE`
